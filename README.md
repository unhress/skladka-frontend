# skladka-frontend

Клієнт (PWA) для застосунку **Skladka** — облік і спліт спільних витрат для 2+ людей.

> **Статус:** заглушка. Реальний фронтенд зʼявиться на фазі **Ф7** дорожньої карти
> (див. `SKLADKA_PLAN.md` у репозиторії [skladka-backend](https://github.com/unhress/skladka-backend)).

## Напрям
- **UI:** преміум-мінімалізм — стильно, стримано, не вульгарно (повітря, типографіка, обмежена палітра, делікатні мікро-анімації).
- **PWA:** встановлення на домашній екран, швидке «Додати чек», Web Share Target («сфоткав → поділився → Skladka»), push-нагадування.
- **Бекенд:** REST API з [skladka-backend](https://github.com/unhress/skladka-backend) (.NET 10), авторизація через JWT.

## Далі
Стек (фреймворк, дизайн-система) обираємо на старті Ф7; цей README буде замінено реальним каркасом застосунку.
